# PideOtra · web

Páginas públicas de PideOtra, servidas con GitHub Pages en https://adanbarea.github.io/pideotra/:

- `index.html`: inicio.
- `privacidad.html`: política de privacidad, con la sección para borrar la cuenta (`#borrar-cuenta`).

Las usan la pantalla de consentimiento de Google (acceso con Google) y la ficha de Google Play.

Aloja también la política de privacidad de Calendario de Turnos (el repositorio de esa app es privado):
`calendario-turnos/privacidad.html`, en https://adanbarea.github.io/pideotra/calendario-turnos/privacidad.html.
